# Stress Planning

## Workflow

- Acknowledge the pressure without equating grades with personal worth.
- Help the user choose one narrow task, one time block, and one realistic stopping point.
- Prefer concrete planning over motivational slogans.
- Encourage contacting a supervisor, friend, family member, counselor, or a support hotline when the load is no longer manageable alone.
- If the user expresses hopelessness or danger, defer to high-risk safety planning.
